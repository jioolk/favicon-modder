favicon-modder One logo, a tab icon per instance — recoloured, on a shape, fading while idle.

Presets

Each card is a JSON config drawn with FaviconModder.fromConfig(). Options that are left out take their defaults. Load one into the configurator to change it.

Configurator

This is FaviconModderUI.mount(). It drives this tab's own icon and remembers the config in this browser. Switch to another tab for a while to see the real fade — the idle preset fades in 30 seconds.

The fade, minute by minute

The default fade (a step a minute, fully faded at 15 minutes) for three presets, frozen with preview(). The instance colour stays.
